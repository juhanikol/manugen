How it works

From observation to approved record

01 / Write

Describe what happened

Write the observation in your own words. If something important is missing, MANUgen asks.

02 / Review

Check the draft

Compare the form with your observation. The model's own suggestions are marked. Correct before approval.

03 / Approve

Save the record

Each approved record is saved as its own file and can also be added as a row to an Excel register.

Also included: chat with Word, Excel, PowerPoint and Outlook attachments, a knowledge base for your own documents, and a workflow builder for your own forms. The user interface is in Finnish.

Available for pilots

Machining knowledge base

A knowledge base prepared for machining is ready for the language model. It is built from Sandvik Coromant learning material, used with permission for non-commercial pilot use, and delivered to pilot participants as a separate package.

The installer itself ships with an empty knowledge base. Do not redistribute the package. Terms

The pilot installation is free of charge. Everything runs on your own computer; an internet connection is needed only to download the language model.

Requirements

64-bit Windows, at least 7 GB of memory and about 6 GB of disk space. No administrator rights needed. The pilot version is not code-signed yet, so Windows may show a warning.
